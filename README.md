# KLGRAM - mini (or not) messanger
KLGRAM is a full stack messenger application build for learning and partfolio.

## Tech Stack:

### Backend 
- Java
- Spring Boot
- Spring Security (Planned)
- MySQL (in work)

### Frontend
- React
- Vite

## Project Goals
this project is build to:
- Learn full-stack development
- Practice in frontend and learn how to make backend
- Work with databases (MySQL)
- Build a clean and scalable project architecture

## Current Status
- ✅ Registration page UI
- ✅ Login page
- ⏰ Backend API (in progress...)
- ❌ MySQL database for accounts
